## Shortcuts or command bar quick actions

A command bar is an easy-to-use search bar that provides quick access to all your website's or app's essential tasks and content.

You can simply press **`⌘+K`** on Mac or **`Ctrl+K`** on Windows/Linux to bring up the command window.

<Frame>
  ![Command bar window opened in Cal ID](/images/getting-started/command-bar-1.png)
</Frame>

From here, simply search what you're looking for!

Here's a categorized list of all the pages you can quickly visit using the command bar:

1. Workflows
2. Event Types
3. Apps
4. Bookings
5. Availability
6. Profile
7. Security
8. Admin
9. Developer
10. Installable Apps
