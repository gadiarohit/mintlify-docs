Link a saved availability schedule to a specific event type—like a "Discovery Call" or "Technical Demo"—so bookers only see the hours you want to offer for that meeting. Creating a schedule is only half the battle; you also have to tell each event which schedule to follow.

<Note>
  Schedules are created under **Availability**. If you haven't built one yet, start with [**Create Availability in Cal ID**](/availability/create), then return here to attach it to an event.
</Note>

## How to link a schedule to an event

<Steps>
  <Step title="Select your event">
    Go to the **Event Types** dashboard and click on the specific event you want to edit.
  </Step>
  <Step title="Open the Availability tab">
    Click on the **Availability** tab within that event's settings.
  </Step>
  <Step title="Choose your availability">
    Under the availability dropdown, select the specific name of the schedule you created.
  </Step>
  <Step title="Save">
    Click **Save**.

    <Frame>
      ![Availability tab in event settings](/images/event-types/event-availability-1.png)
    </Frame>
  </Step>
</Steps>
