## Set up an event type to receive payments

[**Cal ID**](https://cal.id/home) provides Razorpay, Stripe and PayPal to allow you to receive payments when someone books your paid event type.

To start taking payments, please follow these steps:

<Steps>
  <Step title="Install Stripe">
    Go to the [**Cal ID apps**](https://cal.id/apps), search for Stripe (Payment gateway), and click **Install**.

    <Frame>
      ![Stripe in the Cal ID App store](/images/apps/stripe-1.png)
    </Frame>
  </Step>
  <Step title="Connect your Stripe account">
    Proceed through to connect your Stripe account with **Cal ID**. Now that Stripe is connected to your account, you can either open an existing event type or create a new one.
  </Step>
  <Step title="Add Stripe to an event type">
    Go to the **Event Types** section and select the event type in which you want to set the payment method. Go to the **Apps** tab, toggle the payment method, and simply confirm the price you wish your bookers to pay, then click on **Save**.
  </Step>
</Steps>

That's it. You will receive payments as soon as someone books you using this event type.
