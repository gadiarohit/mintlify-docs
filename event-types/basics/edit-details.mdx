You can update the fundamental information of an existing event type at any time to keep your booking page relevant and accurate.

## How to Access Event Editing

<Steps>
  <Step title="Navigate to Event Types">
    Log in to your [Cal ID](https://cal.id/home) account and click on the [**Event Types**](https://cal.id/event-types) tab in the main sidebar.
  </Step>
  <Step title="Select Event">
    Locate the event type you wish to modify.
  </Step>
  <Step title="Open Editor">
    Click the **Edit** icon on the event card to open the event configuration screen.
  </Step>
</Steps>

## Updating Event Information

### Changing the Event Title

- **Action**: Locate the **Title** field of the event setup page.
- **Update**: Enter the new title for your event. This is the main title your bookers will see.

<Frame>
  ![Editing the event title](/images/event-types/edit-details-1.png)
</Frame>

### Modifying the Event URL

- **Action**: Find the **URL** field located below the Interface Language.
- **Update**: Enter a new URL slug. For example, changing the slug from `meeting` to `quick-chat` changes the link to `cal.id/your-username/quick-chat`.

<Warning>
  Updating the URL will break any existing links you have previously shared.
</Warning>

<Frame>
  ![Modifying the event URL](/images/event-types/edit-details-2.png)
</Frame>

### Updating the Event Description

- **Action**: Locate the **Description** text box.
- **Update**: Edit the text to provide clearer instructions or context about the meeting to your attendees.

<Frame>
  ![Updating the event description](/images/event-types/edit-details-3.png)
</Frame>

### Changing the Interface Language

- **Action**: Scroll down to the **Interface Language** dropdown menu.
- **Update**: Select the preferred language for this specific event type. This changes the text displayed on the booking page for the guest.

<Tip>
  Select Visitor's Browser Language so that the user does not get confused.
</Tip>

<Frame>
  ![Changing the interface language](/images/event-types/edit-details-4.png)
</Frame>

## Saving Your Changes

Once you have made all necessary updates, click the **Save** button in the top right corner of the page to apply the changes to your public booking page.
