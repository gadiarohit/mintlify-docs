Create as many availability schedules as you need and assign a specific one to each event type, so every meeting follows the right set of working hours.

<Steps>
  <Step title="Open the availability section">
    Go to **Availability** and create a new schedule, or open an existing one to edit its hours.
  </Step>
  <Step title="Assign a schedule to each event type">
    Organize your event types by linking each one to a specific schedule. See [**Create Availability in Cal ID**](/availability/create) to link an availability schedule with an event type.

    <Frame>
      ![Multiple availability schedules in Cal ID](/images/availability/multiple-schedules-1.png)
    </Frame>
  </Step>
</Steps>

<Tip>
  Multiple schedules are ideal when you want to dedicate different event types to different time zones, or reserve specific times for specific events. Set up an availability schedule for every time zone you schedule around.
</Tip>
