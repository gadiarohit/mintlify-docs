---
title: "Collective Events"
description: "Let bookers schedule with several team members at once, based on shared or common availability."
icon: "user-group"
---

Collective event types are ideal when the booker needs to book a meeting with several team members at one time. With Cal ID Teams, you can easily create a team event type and select collective scheduling as the scheduling type. You can then pick exactly which team members should co-host this event type collectively.

<Frame>
  ![Selecting collective scheduling and co-hosts](/images/teams/collective-1.png)
</Frame>

Cal ID then evaluates availability on the basis of each member's availability by default. However, you also have an option to put forward a common schedule for this specific event type which will be used as the availability and over-ride each member's availability for this event type.

<Frame>
  ![Setting a common schedule for a collective event](/images/teams/collective-2.png)
</Frame>

When you need a group of team members to attend the same meeting, collective events are fantastic. Seeking a convenient time for all of your team members to attend the meeting is a breeze with this method.
