You can set multiple schedules in the availability section and organize your event types by assigning a specific schedule to each one. See [**Create Availability in Cal ID**](/availability/create) to link an availability schedule with an event type.

<Frame>
  ![Multiple availability schedules in Cal ID](/images/availability/multiple-schedules-1.png)
</Frame>

This feature is useful if you want to dedicate different event types to different time zones, or reserve specific times for specific events. You can set up an availability schedule for every time zone you schedule around.
