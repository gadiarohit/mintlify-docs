title: "Multiple Schedules"
description: "Set up multiple availability schedules and assign the right one to each event type to organize your bookings."
icon: "calendar-days"
---

You can set multiple schedules in the availability section of the application and organize your event types better by customizing your availability, quite simply, by selecting the respective schedule as the availability for an individual event type. You can check [**Create Availability in Cal ID**](/availability/create) to link your availability schedule with an event type.

<Frame>
  ![Multiple availability schedules in Cal ID](/images/availability/multiple-schedules-1.png)
</Frame>

This feature is particularly useful if you wish to dedicate different event types over different time-zones or a specific time for a specific event—you can set up an availability schedule for every time-zone you wish to schedule around.
