Cal ID can append booking details to your custom success URL as query parameters, so your thank-you page can display the booking, track the source, or hand off to your own systems automatically.

When a booking is successfully created, guests can be redirected to a custom success page by enabling **Redirect to a custom URL after a successful booking** in the Event Type's **Advanced** settings. This page documents every query parameter that is forwarded to that URL.

<Info>
  Parameters are only forwarded when the **Forward parameters** option is enabled, which is the default.
</Info>

## Overview

Cal ID automatically appends booking information as query parameters to your custom success redirect URL. These parameters let you display booking details or integrate with your own systems.

**Example redirect URL:**

```text
https://yoursite.com/booking-success?uid=xyz123&title=30min%20Meeting&startTime=2025-01-15T14%3A00%3A00.000Z&attendeeName=John%20Doe&email=john%40example.com
```

## Quick reference

| Parameter | Always included | Description |
| --- | --- | --- |
| `uid` | Yes | Unique booking identifier. |
| `title` | Yes | Event type title. |
| `startTime` | Yes | Start time in UTC. |
| `endTime` | Yes | End time in UTC. |
| `email` | Yes | Primary attendee email. |
| `isEmbed` | Yes | Boolean flag indicating an embed booking. |
| `description` | When available | Event description (when available). |
| `location` | When available | Meeting location (when set). |
| `hostName` | When available | Host name(s) (when available). |
| `hostStartTime` | When available | Start time in host timezone (when available). |
| `attendeeName` | When available | Attendee name (when available). |
| `attendeeStartTime` | When available | Start time in attendee timezone (when available). |
| `attendeeFirstName` | When available | First name from booking form (when provided). |
| `attendeeLastName` | When available | Last name from booking form (when provided). |
| `guestEmails` | When available | Guest emails (when guests added). |
| `phone` | When available | Phone number (when provided). |

## Core booking parameters

| Parameter | Included | Example | Notes |
| --- | --- | --- | --- |
| `uid` | Always | `8uyWEaseQCpJHthpxH0CBO` | Unique identifier for the booking. Use it to fetch additional booking details via API or store in your database. |
| `title` | Always | `30 Minute Meeting` | The event type title. |
| `description` | When event has a description | `Quick sync meeting to discuss project updates` | Event type description. |
| `startTime` | Always | `2024-01-15T14:00:00.000Z` | ISO 8601 start time in UTC. |
| `endTime` | Always | `2024-01-15T14:30:00.000Z` | ISO 8601 end time in UTC. |
| `location` | When location is set | `integrations:gmeet` (Gmeet), `integrations:zoom` (Zoom) | Meeting location or video conference URL. More possible values [here](https://cal.com/help/bookings/prefill-fields#pre-selecting-a-video-meeting). |

## Host / organizer parameters

| Parameter | Included | Example | Notes |
| --- | --- | --- | --- |
| `hostName` | When host information available | `Jane Smith,Mike Johnson` | Host name(s), comma-separated for multiple hosts. |
| `hostStartTime` | When host timezone available | `2024-01-15T09:00:00-05:00` | Start time formatted in the host's timezone. |

## Attendee parameters

| Parameter | Included | Example | Notes |
| --- | --- | --- | --- |
| `attendeeName` | When primary attendee name available | `John Doe` | Name of the person who booked. |
| `attendeeStartTime` | When attendee timezone available | `2024-01-15T06:00:00-08:00` | Start time in the attendee's timezone. |
| `attendeeFirstName` | When first name provided in booking form | `John` | First name from the booking form. |
| `attendeeLastName` | When last name provided in booking form | `Doe` | Last name from the booking form. |
| `guestEmails` | When additional guests added | `guest1@example.com,guest2@example.com` | Comma-separated list of guest emails. |

## Booking context parameters

| Parameter | Included | Example | Notes |
| --- | --- | --- | --- |
| `email` | Always | `john@example.com` | Primary attendee's email address. |
| `phone` | When phone number provided | `+1234567890` | Phone number from the booking form. |

## System context parameters

| Parameter | Included | Example | Notes |
| --- | --- | --- | --- |
| `isEmbed` | Always | `false` | Boolean flag indicating whether the booking was made via embed. |

## Troubleshooting

<AccordionGroup>
  <Accordion title="Missing parameters">
    Some parameters are only included when data is available.
  </Accordion>
  <Accordion title="URL encoding issues">
    Always use `decodeURIComponent()` in JavaScript or the equivalent in other languages. Special characters like `@`, `+`, and spaces are URL encoded.
  </Accordion>
  <Accordion title="Date / time handling">
    `startTime` and `endTime` are always in UTC (ISO 8601 format). `hostStartTime` and `attendeeStartTime` include timezone information. Convert to local time as needed for display.
  </Accordion>
</AccordionGroup>

## Security considerations

<Warning>
  Always validate and sanitize parameters before using them in database queries. Don't trust parameter values — validate them against your expected data types.
</Warning>
