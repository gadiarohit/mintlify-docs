Jump to any page or trigger any action in Cal ID in a few keystrokes — no clicking through menus. The command bar is a search box that surfaces all of your account's essential tasks and content in one place.

## Open the command bar

Press the shortcut for your platform to bring up the command window from anywhere in Cal ID:

<Tabs>
  <Tab title="Mac">
    <kbd>⌘</kbd> <kbd>K</kbd>
  </Tab>
  <Tab title="Windows / Linux">
    <kbd>Ctrl</kbd> <kbd>K</kbd>
  </Tab>
</Tabs>

<Frame caption="The Cal ID command bar, ready for your next action.">
  ![Command bar window opened in Cal ID](/images/getting-started/command-bar-1.png)
</Frame>

From here, simply start typing what you're looking for and select a result to jump straight to it.

<Tip>
  The command bar works from any page — memorize <kbd>⌘</kbd> <kbd>K</kbd> (or <kbd>Ctrl</kbd> <kbd>K</kbd>) and you'll rarely need the sidebar again.
</Tip>
