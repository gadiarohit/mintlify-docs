Collective event types are ideal when a booker needs to meet with several team members at once. Cal ID finds a time that works for everyone and puts them all on the same booking.

<Info>
  In a collective event, **all selected co-hosts must attend** the meeting. Cal ID only offers slots where every co-host is free, so the booker always lands on a time that works for the entire group.
</Info>

## Create a collective event

<Steps>
  <Step title="Create a team event type">
    From your team, create a new event type and select **Collective** as the scheduling type.
  </Step>
  <Step title="Pick your co-hosts">
    Choose exactly which team members should co-host this event type collectively.

    <Frame>
      ![Selecting collective scheduling and co-hosts](/images/teams/collective-1.png)
    </Frame>
  </Step>
  <Step title="Set availability (optional)">
    By default, Cal ID evaluates availability based on each member's individual schedule. You can instead put forward a **common schedule** for this specific event type, which overrides each member's availability for this event only.

    <Frame>
      ![Setting a common schedule for a collective event](/images/teams/collective-2.png)
    </Frame>
  </Step>
</Steps>

When you need a group of team members to attend the same meeting, collective events are fantastic. Seeking a convenient time for all of your team members to attend is a breeze with this method.
